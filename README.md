# Amplitube5-Uninstaller

## How to use

1. Download *script.zsh*
2. Open terminal
3. Do

    `xattr -d com.apple.quarantine FILE_LOCATION` : disable quarantine flag on script 
    
    `chmod +x FILE_LOCATION` : grant exec privilege to script

   (To fill `FILE_LOCATION`, just drag *script.zsh* from finder to terminal)
